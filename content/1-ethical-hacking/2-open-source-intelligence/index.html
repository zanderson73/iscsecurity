Open Source Intelligence & Attack Surface Discovery

Master the techniques required to collect, analyze, and leverage publicly available information while mapping operational infrastructures and discovering external digital footprints.

Module Overview

This module introduces the methodologies and technical toolsets used in advanced open-source intelligence investigations. We will learn the structured OSINT intelligence cycle, advanced target search mechanics, operational security considerations, automated infrastructure enumeration techniques, and breach data analysis.

Learning Objectives

  • Understand the phases of the structured Open Source Intelligence Cycle.
  • Configure secure, sandboxed investigative environments using virtual machines.
  • Construct advanced search queries and Google Dorks to locate exposed targets.
  • Enumerate target infrastructure via domain logs, IP addresses, and IoT engines.
  • Investigate compromised profiles using leak repositories and username pivot tracking.
  • Maintain operational security (OPSEC) to defend your profile during online tracking.
